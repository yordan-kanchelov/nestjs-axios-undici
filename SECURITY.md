# Security Policy

Security fixes are released for the latest published version of `nestjs-axios-undici`.

To report a vulnerability, use [GitHub private vulnerability reporting](https://github.com/yordan-kanchelov/nestjs-axios-undici/security/advisories/new) instead of opening a public issue. Include the affected version, a description of the issue and, if possible, steps to reproduce it. You should get a response within a week.
